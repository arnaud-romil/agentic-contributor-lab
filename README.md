# agentic-contributor-lab
Hands-on lab for GitHub Agentic AI concepts

## TODO application

Run the interactive command-line application with:

```bash
python3 app.py
```

Choose an option to add, list, complete, or delete tasks. Task descriptions must not be empty; duplicate descriptions are allowed. Tasks and their IDs are stored only in memory while the application is running. Exiting the application clears all tasks.

Run the unit tests with:

```bash
python3 -m unittest
```
